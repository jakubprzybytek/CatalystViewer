# Jobs Log Implementation Plan

Goal: Implement persistent workflow job logging and a dedicated Jobs page based on the approved design in docs/superpowers/specs/2026-06-01-jobs-log-design.md.

Architecture: Add a dedicated jobs read model in DynamoDB, write compact summaries from both Step Functions workflows, expose list and detail APIs, and render a separate web view reachable from a new header menu.

Tech stack: SST, AWS Step Functions, AWS Lambda, DynamoDB, TypeScript, Next.js, React, MUI, Vitest.

Scope constraints:
- New executions only, no backfill.
- All authenticated users can view Jobs.
- Unit tests only in this story.
